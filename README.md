## 👤 Sobre Mim

Sou desenvolvedor com foco em **backend, sistemas e engenharia de software**, com experiência prática construindo aplicações, APIs, ferramentas de desenvolvimento, automações e projetos que envolvem arquitetura, bancos de dados, redes e infraestrutura.

Meu interesse principal está no funcionamento interno dos sistemas: **como os componentes se comunicam, como os dados fluem, onde estão os gargalos e como projetar algo que continue compreensível conforme cresce**.

Ao longo dos projetos, venho trabalhando com diferentes níveis da stack, desde ferramentas de linha de comando e análise de código até sistemas web completos, APIs, autenticação, persistência, concorrência, observabilidade e infraestrutura.

Também exploro projetos de nível mais baixo quando o problema exige entender melhor o funcionamento do sistema, incluindo **C/C++, memória de processos, estruturas de dados, offsets, comunicação com processos e APIs do sistema operacional**.

Atualmente, meus projetos mais relevantes estão concentrados no ecossistema **Arch**, especialmente no desenvolvimento do **ArchMAP** e de ferramentas complementares para análise e integração de sistemas.

# 🚀 Projetos em Destaque

## 🗺️ ArchMAP

**Análise arquitetural de codebases · Open Source**

Ferramenta para analisar a estrutura e as dependências de projetos de software sem precisar executar a aplicação.

O projeto nasceu da necessidade de entender codebases grandes e identificar problemas arquiteturais de forma objetiva.

### Principais recursos

* Análise de dependências entre arquivos e módulos
* Detecção de dependências circulares
* Componentes fortemente conexos utilizando **Tarjan / SCC**
* Grafos de dependência
* Análise de arquitetura e estrutura do projeto
* Detecção de riscos arquiteturais
* Health score e classificação
* Regras configuráveis
* Histórico e análise baseada em Git
* `trace` para análise de alcançabilidade
* `diff` para comparação de snapshots
* `advise` com integração a provedores de LLM
* Interface local para exploração dos resultados
* CLI
* Extensão para VS Code
* Suporte a múltiplas linguagens

**Stack:** Python · Graph Algorithms · AST/Parsing · Git · CLI · LLM Integration

[ArchMAP](https://github.com/Kaua-KGzin/ArchMAP)
